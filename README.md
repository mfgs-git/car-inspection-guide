# Car Inspection Guide

A responsive, mobile-first photo checklist inspired by the supplied screen recording. It guides a user through the required vehicle-condition photos and saves progress locally in the browser.

## Run locally

Open `dist/index.html` in a browser, or serve the `dist` directory with any static web server.

## Features

- 12-step inspection checklist grouped by vehicle area
- Full-screen photo guidance with previous/next navigation
- Persistent completion status using local storage
- Responsive desktop and mobile layout
- Keyboard navigation and accessible labels
